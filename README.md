# 恐竜リスト (Dinosaur List)

ARK: Survival Evolved の恐竜・アイテム販売管理用 Web アプリです。

## 機能

- **恐竜 / アイテム一覧** の表示・検索（五十音順）
- **数量・納品区分** の選択と合計金額の自動計算
- **コピー** ボタンで注文テキストをクリップボードへ出力
- **帳簿** ボタンで売上テキストを出力
- **管理モーダル**（一覧 / 価格 / 画像）で恐竜・アイテムの追加・編集・削除
- **ルームモーダル** でルーム情報の管理
- データは `localStorage` に保存（インストール不要・オフライン動作）

## ファイル構成

| ファイル | 説明 |
|---|---|
| `index.html` | アプリの HTML |
| `app.js` | アプリのロジック（Vanilla JS） |
| `style.css` | スタイルシート |
| `dinos.txt` | 恐竜マスターデータ |
| `items.txt` | アイテムマスターデータ（名前 &#124; 個数 &#124; 単価） |
| `version.json` | ビルドバージョン情報 |

## 使い方

ローカルサーバーまたは静的ホスティングで `index.html` を開くだけで使用できます。

```bash
# Python の簡易サーバーを使う場合
python3 -m http.server 8080
```

ブラウザで `http://localhost:8080` を開いてください。
